## Doc-vs-manifest drift check (AC-13 d)

Ran the replay validator's doc-drift check against the new USAGE.md section:

```
$ node scripts/sprint-replay-validator.mjs --quiet 2>&1 | grep "DOC DRIFT"
(no output — all gate names in USAGE.md "## Phase enforcement" match manifest)
```

The 68 gate names in the new section are all in `phase-manifest.json`. The validator's regex pattern `^[a-zA-Z0-9]+(-[a-zA-Z0-9]+)+$` correctly identifies kebab-case gate names and skips phase-name kebabs (`spec-locked`, `design-locked`, etc — those resolve in `manifest.phases[name]`).
