1. **Redact primitive** — `sprint-pii-redact.sh` catches 6 PII pattern classes (email, UUID, JWT, API key, password=, postgresql://)
2. **Redact-then-search chain** — `sprint-pii-redacted-search.sh` wraps primitive + emits would-search-with output; verified PII-free
3. **Real WebSearch invocation** — actually called the real WebSearch tool with redacted query, search executed and returned 10 real results
