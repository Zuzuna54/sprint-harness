# AC-39 — PreToolUse Bash forbidden-actions

**Verdict:** ✓ PRODUCTION

## Live evidence (this sprint)

When I tried to write spec content containing the literal string "git push" inside a heredoc, the hook BLOCKED the entire bash invocation:

> `BLOCK Forbidden during sprint harness-full-coverage: ...` matches `/\bgit\s+push\b/i`

That's the inject-catch in one shot:

- Bash command contained forbidden pattern → blocked
- Even though the pattern was in a comment/heredoc string, the regex caught it
- Bypass requires explicit `SPRINT_DRIFT_BYPASS=1`

- pulumi up/destroy
- rm -rf
- raw DELETE FROM
