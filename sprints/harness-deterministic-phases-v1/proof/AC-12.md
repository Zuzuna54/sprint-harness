# AC-12 — Retro completeness in sprint-end.sh

**Verdict:** Production
**Methodology:** template + validation block + manifest predicate enforcement

## Changes shipped

### sprint-end.sh retro template (updated)

Sections required by `phase-manifest.json:done.required_artifacts`:

- `## What worked` (≥50 chars)
- `## What didn't` (≥50 chars)
- `## What surprised us` (≥50 chars)
- `## Patterns extracted` (≥100 chars body, with 3+ `### Pattern N: <name>` subheadings)
- `## CLAUDE.md updates proposed` (≥10 chars)
- `## Open follow-ups` (≥10 chars)

Template now ships `### Pattern 1/2/3: <name>` subheading placeholders under Patterns Extracted so operators don't forget to fill them.

### sprint-end.sh validation block (new)

Before delegating to `sprint-advance-phase.sh done`, the script:

1. For each required H2 heading: parse body with awk (heading-scoped), strip italic-only placeholder lines, count non-space chars. If ≥50 → `record_sub_step retro-<gate>`. Else: don't record → manifest predicate fails → advance-phase refuses.
2. Count `### Pattern N: <non-empty-name>` subheadings under `## Patterns extracted`. If ≥3 → record `retro-pattern-1`, `retro-pattern-2`, `retro-pattern-3`.
3. Always record `velocity-computed` (metrics.json was just written), `trajectory-closed`, `daa-feedback-batched`.
4. Regenerate `dashboard.html` BEFORE delegation so the done-phase manifest's `file_exists dashboard.html` predicate is satisfied.

## Inject-violation scenarios this catches

| Attempt to close sprint with…              | Caught by                                                 | Result                                                               |
| ------------------------------------------ | --------------------------------------------------------- | -------------------------------------------------------------------- |
| empty retro.md                             | sprint-end.sh validation block + manifest predicates      | 6 [FAIL] file_contains_heading + 8 [FAIL] sub_step_recorded → exit 1 |
| retro with only italic-placeholder content | grep -vE strips placeholders → real=0 chars               | [FAIL] file_contains_heading → exit 1                                |
| retro with only 2 patterns (not 3)         | awk pattern-count returns 2; retro-pattern-3 not recorded | [FAIL] sub_step_recorded: gate 'retro-pattern-3' → exit 1            |
| missing metrics.json                       | manifest file_exists predicate                            | [FAIL] file_exists: metrics.json → exit 1                            |
| missing dashboard.html                     | manifest file_exists predicate                            | [FAIL] file_exists: dashboard.html → exit 1                          |
| inline `jq '.phase = "done"' state.json`   | AC-5 PreToolUse hook                                      | BLOCK exit 2 — never reaches state                                   |

## What this proves

1. **Operator cannot fast-path to `phase=done`** — sprint-end.sh's advance-phase delegation requires retro completeness + metrics + dashboard. Each requirement traces to a predicate or sub-step in the manifest.
2. **Template placeholders count as 0 chars** — italic `_(Claude proposes…)_` lines are stripped by `grep -vE '^_[^_]*_[[:space:]]*$'` so operators can't trivially leave the template untouched.
3. **3-pattern minimum is enforced** — `### Pattern N: <name>` subheadings with non-empty names. Forces actual pattern extraction, not just a section header.
4. **Dashboard regenerated pre-advance** — fixes the chicken-and-egg where dashboard.mjs ran AFTER state.phase=done.
